# nevambla-code

An editor-style Herdr window in Dracula colors: a title bar, an activity rail, a file explorer and one workspace of native tabs. Files and terminals share Herdr's splits, pane dragging and zoom.

![nevambla-code](../preview.png)

## What you see

The `dracula` theme, JetBrainsMono Nerd Font at 13 px and terminal padding 6 × 12 apply throughout.

1. **Title bar** (`vsc-titlebar`, 45 px): a centered 380 px command center showing the active Space, a sidebar toggle and a 24-hour clock. It drags the window. The system title bar is hidden; traffic lights sit at 14, 11. Claude usage is optional and disabled by default.
2. **Activity bar** (`vsc-activity`, 48 px): Explorer, Source Control and Spaces at the top; Agents directly above Settings at the bottom. The middle area shows a scrollable compact agent rail while the full list is hidden, aligned toward the bottom. The Agents button uses a Lucide SVG; agent identities use Herdr program icons with a small status light at the top-right.
3. **Sidebar** (378 px by default, resizable 170–520): one stack showing `vsc-explorer`, `vsc-changes` or Herdr's `spaces`. An independently resizable Agents list occupies the lower sidebar when expanded.
4. **Workspace**: a 36 px `vsc-panelbar` over the active native tab. Tabs are 160 px, aligned left; + follows the last tab and spare space remains to the right. Pane frames have square corners, a 1 px border, zero gap and an always-visible 28 px `vsc-pane` header. Files and terminals use the same area.

## How it behaves

- **Agents:** `vsc-agents` lists them by state. Blocked and done agents need attention and sort first. A parent takes the place of its most urgent sub-agent. A done agent you have looked at stays in Done until you leave it. The activity bar’s bottom Agents button toggles the full list without changing the selected Explorer/Git/Spaces view or the list’s remembered size; the list header can also hide it. The compact rail appears whenever the full list or the whole sidebar is hidden. Each icon has a corner status light: working breathes over 2.4 seconds, blocked over 1.4 seconds, and done, idle and unknown stay steady in their theme colors. Task, space and address appear in its tooltip. Clicking focuses the captured agent address locally or over SSH. Pinned agents stay first, then priority or space order as selected; agent-next navigation follows the displayed order. The button badge counts blocked and unseen done agents. No redraw timer is used for the rail: status is live and opacity animates natively with ease-in-out timing.
- **Native files:** Explorer, Git and path navigation create native `vsc-editor` tabs in the captured Space. Identity includes source machine and path; diffs are separate. Existing tabs are selected rather than duplicated. Async creation never switches the user back after a Space change. The native document retains tab lists and splits per Space. Earlier editor-group lists migrate when their Space is activated: both lists are validated before creation, duplicates are consolidated and original lists remain intact. Failed migration shows Restore files · Retry.
- **File actions:** double-click a tab to rename it. File tabs offer Rename, Close and Close Others. Close Others only closes other file-preview-only tabs in that Space; terminal work and mixed tabs remain. Dirty files stay open with a notice. File headers split a copy right/down, zoom or close; tab-bar split controls add terminals. Herdr's native grip moves panes. ⌘J zooms/restores the focused pane; ⌘B toggles the sidebar.
- **Editing and recovery:** documents load only while visible, including native splits, so large restored lists do not flood remote reads. Failures show their cause and Retry. Local text uses native editing; SSH text is read-only because Herdr's write API is local only. ⌘S saves with an expected-text conflict check; ⌘W closes the focused file pane. Unsaved buffers persist locally for recovery; failed saves retain them. Corrupt recovery records show an error and are preserved. Markdown toggles with ⌘⇧V. Python runs with ⌘⌥R on its source machine, using the nearest `.venv` or `python3`. Notebooks run cells on a real Jupyter kernel with ⇧↩ / ⌘↩; PDFs render page by page.
- **Images:** PNG, JPEG, GIF, WebP, SVG and BMP display in native file panes, locally and over SSH. Fit (without enlargement), 1:1, zoom buttons, pinch and scrolling preserve aspect ratio. A helper checks source bytes and dimensions before publishing an immutable SHA-256 cache entry; an existing corrupt entry is an explicit error. Limits are 64 MiB and 64 million pixels. Remote images use the same verified SSH command stream as transfers.
- **Nix and IC previews:** Nix (.nix), Verilog/SystemVerilog (.v, .vh, .sv, .svh, .verilog), Verilog-A/AMS (.va, .vams), VHDL (.vhd, .vhdl), SPICE/CDL (.sp, .spi, .spice, .cir, .ckt, .cdl, .spf, .dspf, .net, .netlist) and Spectre (.scs, .spectre) have colored tokens, virtual rows, horizontal scrolling and line numbers. Copy preserves the complete buffer. Edit switches to plain text; Preview/⌘⇧V highlights current unsaved text. Grammar errors are explicit. Bundled tokenization works identically for local and SSH files.
- **Navigation and Explorer:** ⌘⇧O accepts absolute/relative paths, `~/` and local `file://` URLs, validates on the captured machine, pins Explorer to the folder and opens files as native tabs. The current file's folder/machine remain the browsing context when its tab is focused. Ignore rules dim untracked ignored names/icons while keeping them browsable. Nested rules, negations, global excludes and `info/exclude` work locally and over SSH; Git read errors are visible.
- **Git:** follows Explorer's pinned folder and uses matching chrome, compact headings, icons and rows. Selecting a change opens a read-only native Diff tab with old/new line numbers and red/green changed lines. Visible diffs refresh every ten seconds and on demand. New, deleted, binary and truncated previews have explicit states. Commit stages and commits only after the user presses Commit.
- **Transfers:** Explorer captures the source machine/path and copies individual regular files to another registered SSH machine or this computer. SSH command streams verify size and SHA-256, publishing a numbered sibling when the destination exists. Remote-to-remote copies use a temporary local spool. Success provides Copy destination path and Done; errors stay visible.
- **Terminal tabs:** native selection, double-click rename and Herdr's right-click menu (Rename, New tab, Close). A draggable horizontal scrollbar remains visible when tabs overflow; the active tab scrolls into view on selection. Tab status dots use the rail's static red/green/blue colors.
- **Optional usage:** title bar `props.show_usage: true` enables Claude account reads and polling. `props.accounts` specifies account names and optional config directories/commands/IDs. Clicking opens the usage dropdown. Refresh is every five minutes and on demand; failures show the actual error and clear the reading.

## Built from

- **Layout:** `layouts/nevambla-code.json`: root column of titlebar and body; body row of activity, side (`side-body` stack above independently hidden `agents-list`) and work (`panelbar`, then `main` native tab block).
- **Mods:** `vsc-titlebar`, `vsc-usage`, `vsc-activity`, `vsc-explorer`, `vsc-jump`, `vsc-transfer`, `vsc-changes`, `vsc-agents`, `vsc-editor`, `vsc-panelbar` and `vsc-pane`. Herdr's own mods remain unchanged. The Spaces view uses Herdr's original `spaces` mod. SVG controls reuse shipped assets or the bundled official Lucide assets.
- **Native pane IDs:** the app supplies IDs to headers but not file content. Local Python `bind-panes.py` uses public `hc connect` `doc.get` / `doc.set` to persist the actual node ID as `preview_pane` in file props. Compare-and-swap retries reread concurrent updates; only that metadata changes. Invalid schemas, unavailable documents and exhausted conflicts show errors and Retry. `herdr-app do tab.new` returns the actual creation IDs.
- **Shared state:** `vsc.file-panes` indexes live native pane metadata; `vsc.file-opening` deduplicates concurrent opens; `vsc.file-buffer:<encoded Space/file identity>` and per-pane recovery copies retain edits; `vsc.files.migrated:<encoded Space>` records migration completion. Identical `files.js` helpers live in the editor, Explorer, Git, jump, tab-bar and pane mods because imports are isolated. `vsc-panelbar/legacy-files.js` only reads earlier group lists. Existing sort/pin, Explorer, usage and transfer keys remain. Shared state and caches are excluded from the repository.
- **Programs and files:** Navigation uses Python on the captured machine; Git reads disable optional locks and external diff drivers. Transfers and remote images use local Python, `hc machine ls`, `/usr/bin/ssh` with the user's SSH config, and remote Python. Images, notebook state and PDF pages cache under `data/vsc-editor/`. Notebooks additionally need `jupyter_client` and `ipykernel`; PDFs use poppler's `pdftoppm`/`pdfinfo` and `open`. Enabled Claude usage reads the macOS Keychain and calls Anthropic's usage API.
- **Installation:** `install.sh` backs up replaced files, preserves personal shortcuts and migrates only the exact earlier terminal-panel preset bindings. Default ⌘J is now native `pane.zoom`.
