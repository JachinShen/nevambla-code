# nevambla-code

An editor-style herdr window in Dracula colors: a slim title bar with your Claude plan usage, an activity bar, a file explorer with your spaces and agents underneath, an editor with tabs, and the herdr terminals in a panel beside it. Agents run in the terminals while you read and edit their files next to them.

![nevambla-code](../preview.png)

## What you see

Left to right under a 45 px title bar, all in the `dracula` theme with JetBrainsMono Nerd Font at 13 px and terminal padding 6 × 12:

1. **Title bar** (`vsc-titlebar`, 45 px, drags the window, system title bar hidden, traffic lights at 14, 11). On the left: "Claude" in #d97757 with two small meters, Session (5 h) and Week (7 d), each showing the percent left and the time until it resets. In the center: a 380 px command-center box with the active space's name ("<space> — Herdr") that opens the palette. On the right: side bar and editor toggles, then a 24 h clock.
2. **Activity bar** (`vsc-activity`, 48 px): icons for Explorer, Source Control (Changes) and Spaces. Clicking the shown one again hides the side bar.
3. **Side bar** (378 px, resizable 170–520, chrome background): a stack showing one of `vsc-explorer` (the focused pane's folder as a tree), `vsc-changes` or herdr's `spaces`. Underneath, a resizable dock with `vsc-spaces` (one row per space in its herdr color, + for a new one) above `vsc-agents` (agents grouped or by priority) in a 1 : 2 ratio.
4. **Editor** (`vsc-editor`, about 40 % of the remaining height): file tabs, breadcrumbs and an editable code view; a second group (`props.group: 2`) is there for splits and starts hidden.
5. **Terminal panel** (below the editor, about 60 % of the remaining height): a 36 px `vsc-panelbar` (160 px terminal tabs aligned left, the + button immediately after the last tab, spare space, then split, move and maximize on the right) over the active tab's panes. Panes are square-cornered with a 1 px border, no gap, and a 28 px `pane` header always shown on top.

## How it behaves

- **Agents:** `vsc-agents` lists them by state. Blocked and done agents need attention and sort first. A parent takes the place of its most urgent sub-agent. A done agent you have looked at stays in Done until you leave it.
- **Usage:** hovering or clicking "Claude" opens `vsc-usage`, a 470 px dropdown with every configured account and its meters. Clicking an account shows it in the title bar. Usage refreshes every 5 minutes and on click. A failed refresh shows the returned error in the title bar and dropdown and clears the old reading. Accounts come from the title bar block's `props.accounts` (`name`, optional `config_dir`, `command`, `id`); without them the default `claude` login is shown.
- **Files:** clicking a file in the Explorer opens it in the last-used editor group. Git-ignored files and folders keep their place in the tree with dimmed names and icons, on local and SSH machines. Git checks include nested ignore rules, negations, global excludes and `info/exclude`; tracked files keep their normal colors. Failed Git reads show an error below the tree. ⌘S saves, ⌘W closes, ⌘⇧V toggles a Markdown preview, ⌘⌥R runs a Python file. `.ipynb` files open as notebooks whose cells run on a real Jupyter kernel (⇧↩ or ⌘↩). PDFs render page by page.
- **Navigation:** ⌘⇧O accepts an absolute path, a path relative to the focused terminal, `~/`, or a local `file://` URL. It checks the path on that terminal’s machine, pins Explorer to the resolved folder and opens ordinary files in the active editor group. A pin expires when the terminal directory or machine changes.
- **Transfers:** Explorer’s transfer action captures the source machine and path. The dialog chooses a different registered SSH machine or this computer and an existing destination folder. Copies run over SSH command streams, verify size and SHA-256, and publish without overwriting an existing file. Remote-to-remote copies pass through a temporary local spool. Success provides a button to copy the destination’s absolute path, and a completion button that closes the dialog. Failures display the actual error.
- **Git:** `vsc-changes` follows the same machine and folder pin as Explorer. Its left sidebar uses the same chrome background, 35 px uppercase heading, collapsible 22 px repository heading and 22 px file rows as Explorer. File icons align with Explorer, filenames precede muted parent paths, and status letters sit at the right edge. A compact commit field sits at the bottom. Selecting a file opens a distinct read-only Diff tab in the last visible editor group, without replacing an editable tab for the same path. Diff identities include machine, repository and relative path. The main editor shows old/new line numbers and red/green changed lines, refreshes the active diff every 10 seconds, and offers manual refresh. New, deleted and binary files have explicit states; long previews show a truncation notice and failed reads show errors. The commit action stages all changes and commits the entered message only when the user presses Commit.
- **Terminal tabs:** double-click renames; clicking selects. Right-click opens Herdr's tab menu (Rename, New tab, Close), targeting the clicked tab without selecting it first. The active tab scrolls into view. The bar stays left aligned, with 160 px tabs and a + button immediately after the tabs.
- **Panels:** ⌘B toggles the side bar, ⌘J the terminal panel, ⌘⌥J moves the terminal panel between the bottom and the right.

- **Nix and IC previews:** Nix (.nix), Verilog/SystemVerilog (.v, .vh, .sv, .svh, .verilog), Verilog-A/AMS (.va, .vams), VHDL (.vhd, .vhdl), SPICE/CDL (.sp, .spi, .spice, .cir, .ckt, .cdl, .spf, .dspf, .net, .netlist) and Spectre (.scs, .spectre) open in a read-only highlighted view with virtual rows, horizontal scrolling and line numbers. The toolbar identifies the language and mode. Copy uses the complete original buffer, preserving tabs and line endings. Edit switches to native plain-text editing and Preview (also ⌘⇧V) re-highlights the current unsaved buffer. Grammar errors clear the old preview and show an explicit message with the Edit option. Tokenization runs locally for both local and SSH files, with bundled Prism and circuit-specific rules; it starts no helpers and performs no network requests.

## Built from

- **Layout:** `layouts/nevambla-code.json`. Root column: `titlebar` block, then `body` row of `activity` block, `side` column (`side-body` stack of `explorer` / `changes` / `spaces`, then `agents-dock` column of `spaces-switch` and `agents-list`), and `work` column (`editor` row of `editor-1` and hidden `editor-2`, then `termpanel` column of `panelbar` and the `main` tab block).
- **Mods:** `vsc-titlebar`, `vsc-usage`, `vsc-activity`, `vsc-explorer`, `vsc-jump`, `vsc-transfer`, `vsc-changes`, `vsc-spaces`, `vsc-agents` (cloned from herdr's `agents`), `vsc-editor`, `vsc-panelbar`; herdr's own `spaces` and `pane`.
- **Shared state:** `vsc.usage`, `vsc.usage.shown`, `vsc.editor`, `vsc.editor.2`, `vsc.group`, `vsc.sections`, `vsc.explorer.jump`, `vsc.transfer.destinations`, `vsc.transfer.completed`. Shared state stays local and is excluded from the repository.
- **Programs:** `vsc-jump` uses Python 3 on the focused machine to validate paths. `vsc-changes` and the editor diff use Git on the captured machine; Git reads disable optional locks and external diff drivers. `vsc-transfer` uses local Python 3, `hc machine ls`, `/usr/bin/ssh` and remote Python 3. The SSH client reads its normal configuration.  `vsc-titlebar/usage.sh` reads the Claude Code login from the macOS Keychain and calls `https://api.anthropic.com/api/oauth/usage`. `vsc-editor` runs `python3` with `kernel.py` (needs `jupyter_client` and `ipykernel`), `pdftoppm` and `pdfinfo` from poppler, and `open`. Caches go to `data/vsc-editor/`.
- **Art:** small stroke SVG icons in each mod folder; the `dracula` theme in `themes/dracula.json`; JetBrainsMono Nerd Font.
